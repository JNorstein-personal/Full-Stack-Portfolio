H/exicon — Online Digital Board Game



Path: projects/hexicon/README.md



H/exicon is a turn-based digital board game developed in Godot using C#.



The project adapts a multiplayer board-game concept into a software application with an emphasis on reusable game systems, board generation, game-state management, user-interface development, and eventual asynchronous online multiplayer.



Technology

Godot Engine

C#

Object-oriented programming

Game-state management

Procedural or programmatic board construction

UI development

Multiplayer architecture

Linux-based server hosting

Project Goals



The project is intended to support a four-player digital board-game experience across supported platforms while separating core game rules from presentation and networking responsibilities.



Areas of development include:



Board generation

Turn management

Game rules and validation

Player-state management

Reusable UI components

Cross-platform behavior

Asynchronous multiplayer

Client/server communication

Persistent game state

Self-hosted multiplayer infrastructure

Portfolio Focus



H/exicon demonstrates applied C# development beyond conventional business applications, including object-oriented design, interactive systems, state-driven software, UI implementation, and networking considerations.



Status



Active development



The project is being developed iteratively, with individual gameplay systems validated before complete multiplayer integration.



Development Note



AI-assisted tools may be used for planning, debugging, documentation, and code review. Game rules, software architecture, implementation, testing, and final design decisions remain under the project author's control.
