Self-Hosted Linux Infrastructure, Networking \& Homelab Administration



Path: projects/homelab-infrastructure/README.md



This project documents the design, deployment, administration, and continued development of a self-hosted Linux homelab environment.



Unlike the application-development projects in this portfolio, this directory focuses on infrastructure engineering and systems administration: networking, Linux services, containerization, secure remote access, service deployment, monitoring, backup strategy, and operational documentation.



Infrastructure Areas



The environment incorporates technologies and concepts including:



Ubuntu Server

Linux systems administration

Docker and Docker Compose

OpenWRT

Ethernet and wireless networking

DNS

Reverse proxying

Cloudflare services

VPN and secure remote access

WireGuard

Tailscale

Containerized application hosting

Identity and access management

TLS/HTTPS

Firewall configuration

Backup and recovery

Monitoring and logging

Project Goals



This documentation is intended to demonstrate practical experience designing and maintaining a small self-hosted environment rather than merely installing individual services.



Areas of emphasis include:



Network topology

Service isolation

Secure remote administration

Authentication and authorization

Deployment architecture

Configuration management

Backup and recovery planning

Troubleshooting

Portability and reproducibility

Documentation suitable for future maintenance



Sensitive configuration information, passwords, tokens, private keys, credentials, and other operational secrets are excluded from source control.



Status



Active infrastructure



The homelab is an ongoing operational environment. Documentation will therefore evolve as hardware, network architecture, hosted services, and security practices change.



Development Note



AI-assisted tools may be used for research, troubleshooting, planning, documentation, and configuration review. Infrastructure changes are evaluated, executed, tested, and maintained by the project author.
