# Full-Stack Portfolio

This repository serves as a consolidated portfolio of software development, web development, systems administration, networking, and self-hosted infrastructure projects.

The projects collected here reflect work completed while developing practical experience across full-stack development, application architecture, Linux administration, networking, deployment, data handling, accessibility, and user-interface design. Projects range from production-oriented web applications and multiplayer game development to self-hosted infrastructure and smaller experimental utilities.

## Repository Structure

Projects are organized under the `projects/` directory:

* **Loreweaver Wedding Website** — Full-stack React/Vite and Node.js/Express wedding website with RSVP functionality, responsive design, accessibility considerations, and self-hosted deployment.
* **Loreweaver Creations Website** — Public-facing website and application platform for Loreweaver Creations.
* **Lor-E** — Self-hosted, RAG-enabled personal AI assistant designed around controlled access to locally managed information and services.
* **H/exicon** — Online digital board game developed in Godot using C#.
* **Self-Hosted Infrastructure** — Documentation and configuration related to Linux systems administration, networking, containerized services, remote access, security, and homelab operations.
* **Small Projects & Utilities** — Smaller applications, tools, experiments, and focused development exercises.

Each project directory contains its own README describing the project's purpose, technologies, architecture, current status, and relevant implementation details.

## Development Approach

These projects emphasize practical implementation, maintainability, portability, documentation, and iterative development. Where appropriate, repositories include design specifications, architectural decisions, test plans, deployment documentation, and other materials that demonstrate not only the finished result but also the engineering process used to produce it.

AI-assisted tools may be used during development for activities such as planning, research, debugging, documentation, and code review. AI assistance is treated as a development aid rather than a substitute for technical ownership: implementation decisions, source code, architecture, testing, and final project output are reviewed, understood, and maintained by the project author.
